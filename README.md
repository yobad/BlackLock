BlackLock is a smart lockbox for your phone. You will be able to set a time at which you would like to start studying and for how long you want to study for. If the time at which you set has passed without your phone being in the box, annoying sounds will start playing to make you put your phone in. Once the phone has been placed in the box, the lid will close and and lock by itself.
